Open **Maintenance** with **Alt+M** for **WinGet - Reinstall** and all fourteen **Legacy Windows Panels** shortcuts. See the [Maintenance guide](/guides/maintenance/) for the available tools and scheduled workflows.

The former Config tab has been removed, along with its optional Windows Features controls, other Fixes, CTT PowerShell Profile controls, and Remote Access setup. This change does not uninstall Windows components, remove an existing PowerShell profile, or disable an existing SSH server.
